A2.1 · Quantities

Count it or measure it.

Use countable and uncountable nouns with some / any / a lot of / much / many / a few / a little. Possession in this lesson is American: I have / I don’t have / Do you have — not have got. Explain forms with evidence. Analyse, listen, infer, and use words in context — not only choose answers.
